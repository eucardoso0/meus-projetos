# 🌐 Projetos Pessoais — HTML, CSS e JavaScript

Este repositório reúne projetos pessoais de desenvolvimento web utilizando tecnologias como HTML5, CSS3 e JavaScript. O objetivo é treinar habilidades de front-end, criar páginas funcionais, interativas e responsivas.

---

## 📌 Etapas de Desenvolvimento

### 1. 🎨 Estrutura e Layout
- Criação de páginas com HTML semântico
- Uso de Flexbox, Grid e Media Queries para layout responsivo
- Separação clara entre estrutura (HTML), estilo (CSS) e comportamento (JS)

### 2. 🖌️ Estilização com CSS
- Personalização com classes, pseudo-elementos e variáveis
- Temas escuros, animações básicas, efeitos de hover e transições
- Organização por arquivos ou direto no HTML (conforme o projeto)

### 3. 🧠 Lógica com JavaScript (quando aplicável)
- Scripts de interação como:
  - Validação de formulários
  - Menus interativos
  - Alternância de temas
- Uso básico de DOM, eventos e lógica condicional

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript ES6+**
- Editor: VS Code

---

## 🎯 Objetivo

- Reforçar a base de desenvolvimento web com projetos práticos
- Criar portfólio de interfaces simples, funcionais e responsivas
- Explorar criatividade em pequenos desafios front-end
